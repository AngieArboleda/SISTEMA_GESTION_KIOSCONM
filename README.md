# KIOSCONM – Sistema de Gestión para Kioscos

## Sobre este proyecto

Este repositorio corresponde a una versión académica inicial de KIOSCONM, desarrollada con HTML, CSS y JavaScript.

Esta versión se centra en el desarrollo frontend y en la implementación de funcionalidades relacionadas con la gestión de productos, ventas y stock.

**Importante:** este repositorio corresponde a la versión académica inicial y no contiene la versión actual del sistema desarrollado para un cliente. La evolución posterior del proyecto continúa en desarrollo y su código fuente no está publicado.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript

## Objetivo

Aplicar conocimientos de desarrollo web mediante la construcción de una interfaz para la gestión de un kiosco.
